# Расчетно-графическая работа по курсу «Численные методы»

Репозиторий содержит программную реализацию алгоритмов решения математических задач в рамках расчетно-графической работы (РГР). Все вычисления, исходные данные и структуры систем уравнений приведены строго в соответствии с требованиями **варианта № 8**.

## Текущая структура проекта

Программный комплекс разделен на изолированные поддиректории по типам решаемых задач:
`labs/lab-01/` — Реализация метода половинного деления для нелинейных уравнений.
`labs/lab-02/` — Реализация методов Ньютона и хорд для трансцендентных уравнений.
`labs/lab-03/` — Итерационное решение систем линейных алгебраических уравнений (СЛАУ).
`labs/lab-04/` — Применение методов простой итерации и Ньютона к системам нелинейных уравнений.

## Спецификация текущих задач (Вариант 8)
