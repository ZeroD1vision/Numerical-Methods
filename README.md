# Расчетно-графическая работа по курсу «Численные методы»

Репозиторий содержит программную реализацию алгоритмов решения математических задач в рамках расчетно-графической работы (РГР). Все вычисления, исходные данные и структуры систем уравнений приведены строго в соответствии с требованиями **варианта № 8**.

## Текущая структура проекта

Программный комплекс разделен на изолированные поддиректории по типам решаемых задач:
`tasks/task-01/` — Реализация метода половинного деления для нелинейных уравнений.
`tasks/task-02/` — Реализация методов Ньютона и хорд для трансцендентных уравнений.
`tasks/task-03/` — Итерационное решение систем линейных алгебраических уравнений (СЛАУ).
`tasks/task-04/` — Применение методов простой итерации и Ньютона к системам нелинейных уравнений.
`tasks/task-05/` — Нахождение собственных значений матрицы (Метод степенных итераций, метод Якоби).
`tasks/task-06/` — Интерполяция функций многочленами Лагранжа и Ньютона.
`tasks/task-07/` — Численное дифференцирование и интегрирование (Методы трапеций, Симпсона).
`tasks/task-08/` — Численное решение обыкновенных дифференциальных уравнений (ОДУ) методами Эйлера (обычный, модифицированный) и Рунге-Кутты.
